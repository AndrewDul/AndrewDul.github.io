# Plan kolejnych zmian

## Priorytet 1 — treść portfolio

- Wspólnie wybrać najlepsze projekty do pokazania na stronie głównej.
- Dodać własne zrzuty ekranu, krótkie demonstracje i pełniejsze case studies.
- Uzupełnić sekcję About o zatwierdzoną biografię, linki oraz aktualne CV.
- Zamienić robocze pozycje Build Log na prawdziwe wpisy.

## Priorytet 2 — kontakt i AI

- Potwierdzić pierwszy e-mail aktywacyjny FormSubmit po rzeczywistym przesłaniu formularza i sprawdzić odbiór wiadomości.
- Przed publikacją dodać krótką politykę prywatności opisującą przekazanie danych formularza do FormSubmit.
- Określić, jakie zatwierdzone źródła może czytać przyszły asystent AI.
- Zbudować backend bez ujawniania kluczy API w GitHub Pages.
- Dodać jasne zasady prywatności i granice odpowiedzi agenta.

## Priorytet 3 — publikacja

- Utworzyć repozytorium GitHub po otrzymaniu zgody.
- Dodać ten folder do repozytorium i uruchomić GitHub Pages.
- Sprawdzić stronę pod własnym adresem GitHub Pages na telefonie, tablecie i komputerze.
- Dopiero później zdecydować o własnej domenie.

## Priorytet 4 — doskonalenie

- Dodać aktywne wskazanie sekcji w nawigacji.
- Rozważyć angielską i polską wersję językową.
- Dodać testy automatyczne dla podstawowych interakcji.
- Zmierzyć dostępność, kontrast i szybkość po dodaniu obrazów.
