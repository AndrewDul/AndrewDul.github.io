# Warehouse Barcode Studio

## Wykonane

- Dodano nową, wyróżnioną kartę projektu i stronę szczegółów.
- Dodano odnośnik do repozytorium oraz działającej wersji GitHub Pages.
- Opis opiera się na README, konfiguracji projektu i opublikowanej wersji aplikacji.
- Nowy projekt jest pierwszy w kolejności. Karuzela dzieli sześć kart na pięć kart na pierwszej stronie desktopowej i jedną pełnowymiarową kartę na następnej.

## Opis funkcji

Warehouse Barcode Studio działa w przeglądarce i tworzy etykiety Code 128, Code 39, Code 93 oraz QR. Obsługuje sprawdzanie poprawności zależne od formatu, import plików biurowych i tekstowych, kolejkę etykiet oraz eksport do PNG, SVG, PDF i ZIP. Drukowanie wykorzystuje natywne okno przeglądarki oraz profile kompatybilne z Zebra ZD220.

## Ważne ograniczenie

Strona otwiera systemowe okno druku, ale nie instaluje sterowników ani nie konfiguruje fizycznej drukarki. Dane etykiet pozostają lokalnie w przeglądarce i nie są wysyłane do API przez aplikację.
